# Прогнозирование потребления электроэнергии
Нейросетевые и статистические модели для прогнозирования суточного потребления электроэнергии.
## Структура репозитория
- [data/](data/)    - собранные и обработанные датасеты
- [docs/](docs/)    - документация по проекту
- [models/](models/)- непосредственно созданные модели
- [utils/](utils/)  - различного рода утилиты для создания и предобработки датасетов
